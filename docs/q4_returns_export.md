# FactSet export: monthly total returns (Q4)

Recorded 2026-11-07, after a probe (`data/raw/factset_returns_probe.xlsx`: July and May 2020
only, used only to check the format; 6 firms' values were seen).

## Screen setup (same as the fundamentals screen, `docs/factset_export.md`)

- FactSet Universal Screening, criterion **Exchange Country Name = United States** (about 32.8k rows).
- **Exclude Inactive Securities unchecked.** This keeps delisted and acquired securities.
  Exclude Secondary Listings and Exclude Non-Equity Securities are checked.
- Columns, in this order: `FSYM_ENTITY_ID`, `P_SYMBOL`, FDS ticker (default column), then
  the monthly returns **in calendar order**. FactSet labels every return column "Compound
  Tot Ret (USD)", so the month is read from the column order. The loader checks this.
- Values are **percent** (AAPL July 2020 = 16.51). The return is compounded, with dividends
  reinvested on the ex-date.
- One file per calendar year: `data/raw/factset_returns_YYYY.xlsx`.

## Probe findings

- Entity IDs resolve to companies, not securities. An acquired firm's entity is now a private
  subsidiary (e.g. Allergan), so the Excel add-in by entity ID returns nothing. Screening is
  security-level and keeps inactive securities.
- The month in which a security delists mid-month is empty (Allergan, May 2020). The rule for
  this month is set in `docs/q4_design.md` §6.
- 103 panel entities have more than one security row (share classes). Selection rule: the
  security whose symbol matches the panel ticker; otherwise the one with the most non-missing
  months.
